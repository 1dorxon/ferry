# The Ferry name and logo

The code is free software under the AGPL-3.0. The **name "Ferry"** (as the name
of this app), **its logo and app icons** are not covered by that licence.
Luitlabs keeps them so people can always tell the official Ferry apart from a
copy.

**Fine without asking:**
- Saying your project is "based on Ferry" or "a fork of Ferry".
- Linking to Ferry, writing about it, and showing it in reviews and tutorials.
- Running an unmodified copy for yourself, your home or your organisation.

**Not without written permission:**
- Publishing an app, extension or website called Ferry, or a confusingly
  similar name, or using the Ferry logo or icons as yours.
- Using the package id `com.dorxon.ferry`, the Chrome extension's listing or
  identity, or the `ferry.luitlabs.in` / `luitlabs.in` names in a fork.
- Pointing a fork's apps at the official server (`ferry.luitlabs.in`). Run your
  own Worker; the README shows how.

If you publish a fork, give it its own name and icon. Everything else the
licence allows, you can do.

Questions: open an issue.
